# LearnCode — интерактивная обучалка программированию

## 📌 Описание проекта
**LearnCode** — это веб-платформа для изучения языков программирования.  
Каждый урок состоит из:
- 📖 теоретической части (объяснение темы),
- 💻 практического задания (код пишется в консоли прямо на сайте),
- 🎬 визуальной анимации, которая оживает при правильном решении задачи.  

Пример:  
В уроке о цикле `for` пользователю нужно «помочь 10 барашкам перепрыгнуть через забор».  
Если код написан верно, на экране проигрывается анимация прыгающих барашков.

---

## 🛠 Стек технологий
- **Frontend:** React, TypeScript, HTML, CSS  
- **Backend:** Node.js, Express / NestJS  
- **Database:** MongoDB (Mongoose)  
- **Дополнительно:**  
  - Проверка кода: [eval5](https://www.npmjs.com/package/eval5) (JS-интерпретатор в sandbox)  
  - Анимации: [Lottie](https://airbnb.io/lottie/)

## 🚀 Как запустить проект локально

### 1. Клонирование репозитория
```bash
git clone https://github.com/username/learncode.git
cd learncode
````

### 2. Установка зависимостей

Фронтенд:

```bash
cd frontend
npm install
```

Бэкенд:

```bash
cd backend
npm install
```

### 3. Запуск

Фронтенд:

```bash
npm run dev
```

Бэкенд:

```bash
npm run start:dev
```

Откройте [http://localhost:3000](http://localhost:3000), чтобы увидеть приложение.
